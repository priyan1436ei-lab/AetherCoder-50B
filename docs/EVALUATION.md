# AetherCoder-50B Evaluation & Benchmarking Guide

This document outlines the evaluation framework for measuring code generation quality, execution accuracy, inference throughput, and latency.

---

## 1. Benchmarking Philosophy

To ensure scientific integrity:
- **No Fabricated Benchmarks**: Benchmark scores must be generated by actual execution harnesses. Unverified scores and comparison charts from unverified models have been removed.
- **Sandboxed Execution**: Generated code is evaluated in isolated subprocesses with configurable timeouts (default: 5 seconds) to prevent infinite loops, hangs, or host system interference.
- **Offline Smoke Testing**: The repository provides curated standard problems (`has_close_elements`, `separate_paren_groups`, `truncate_number`) to allow smoke evaluation offline without large external downloads.

---

## 2. Running HumanEval Evaluation

To evaluate a model checkpoint against the HumanEval harness:

```python
from benchmarks.humaneval_runner import HumanEvalRunner, get_curated_smoke_problems

runner = HumanEvalRunner(timeout_seconds=5)
problems = get_curated_smoke_problems()

# Provide model completions dictionary: {task_id: generated_code}
completions = {
    "HumanEval/0": "    # generated solution\n...",
}

report = runner.evaluate_and_save_report(
    problems=problems,
    completions=completions,
    output_json_path="reports/humaneval_run_1.json",
    model_name="codex-150m-prototype",
    checkpoint_path="checkpoints/prototype_150m/checkpoint_step_5_final.pt",
)

print(f"Pass@1: {report['summary']['pass_at_1'] * 100:.1f}%")
```

### JSON Evaluation Report Schema
Reports are structured as machine-readable JSON:
- `benchmark`: Benchmark harness name.
- `timestamp`: UTC ISO timestamp.
- `model_name`: Evaluated model.
- `checkpoint_path`: Checkpoint file evaluated.
- `environment`: OS, Python version, processor architecture.
- `summary`: `total_problems`, `passed`, `failed`, `pass_at_1`.
- `details`: Per-task pass/fail status and error traces.

## 3. Profiling Latency & Throughput

Use `benchmarks/metrics.py` to benchmark inference latency:

```python
from benchmarks.metrics import LatencyProfiler

profiler = LatencyProfiler()
profiler.start()

# For each generated token in streaming:
# profiler.record_token()

profile = profiler.finish()
print(f"Tokens/Second:         {profile.tokens_per_second}")
print(f"Time to First Token:   {profile.time_to_first_token_sec}s")
print(f"Inter-Token Latency:   {profile.inter_token_latency_ms}ms")
```
